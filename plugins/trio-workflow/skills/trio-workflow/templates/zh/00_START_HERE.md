## 每个方案都是同样的步骤

1. 新开执行对话，贴入 `PROMPTS.md` 里该方案的开工提示词。
2. 到了停点，执行者只回一句：“已到停点 N，材料在 …”。
3. 新开一个审查对话，说“审查<方案>停点N”，附上那句话。这时先不要告诉执行者“通过”。
4. 回到执行者，说：“审查结果见 <RESULT 路径>，请按结果修改后继续。”有决定就写在后面；不写就按默认。
5. 最终停点之前，打开执行者准备的隔离服务走查，把看到的问题告诉执行者。
6. 最终停点通过后，对审查者说“合并并推送”。合并后重启你的服务。

对话中断或变慢时，新开一个对话，贴入恢复提示词。

## 常用口令

| 说什么 | 对谁说 | 结果 |
| --- | --- | --- |
| 审查<方案>停点N | 审查者 | 写出审查结果，列出待你决定的事 |
| 看一下小改 | 审查者 | 只读改动 |
| 合并并推送 / 只合并不推送 | 审查者 | 快进合并，需要时推送 |
| 做收尾 | 审查者 | 列出清理清单，你确认后执行 |
